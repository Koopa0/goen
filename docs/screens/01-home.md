# Batch ① 首頁 Home — 補充需求(接續 goen 元件庫)

沿用已經定案的 goen 設計系統(色彩 token、字體階層、`design-brief.md` 第 5 節元件庫、htmx 藍虛線 / Stripe Payment Element 灰虛線標註圖例),現在請展開**首頁 Home**畫面,桌機版(1440px)與手機版(375px)各一份。

因為首頁是第一個完整頁面,這一批同時要把**全站共用的 Header 與 Footer**定案下來——之後每一批畫面都會直接沿用同一套,不再重畫。

## Header(全站共用)

- 左側:goen logo lockup(icon + wordmark)。**若 Imagen 的 logo mark 圖檔還沒生出來,先用一個簡單的圓形+中央方孔佔位圖示**,之後直接替換,不要卡住畫面進度。
- 中間或右側:搜尋框。請設計「輸入時即時顯示搜尋建議下拉選單」的樣式(**htmx 標註**:輸入時 debounce 後局部更新下拉建議清單,不整頁刷新)。
- 右側:語言切換(繁中/EN)、會員帳號 icon(未登入顯示登入連結、登入後顯示大頭貼/選單)、購物車 icon(含數量 badge)。
- 手機版:漢堡選單收合分類導覽與部分連結,搜尋、購物車、帳號 icon 常駐。

## 分類導覽 Category Nav

- 圖示化入口,約 6–8 個分類(例如:手機、筆電、耳機、智慧穿戴、家電配件、周邊、更多)
- 桌機版可放在 header 下方一整排;手機版可用可橫向滑動的 icon 列,或收進漢堡選單皆可,兩種都提供讓我們選一個定案。

## Hero Banner

- 輪播(2–3 張),每張含商品/活動圖、標題、副標、CTA 按鈕
- 手動左右切換箭頭 + 圓點頁碼指示器,自動輪播即可,**不需要 htmx 標註**,這是純前端行為(CSS/vanilla JS 處理,不涉及 server round-trip)。

## 精選商品區塊(3 組,各自獨立區塊)

1. 新品上市 New Arrivals
2. 熱銷排行 Best Sellers
3. 限時優惠 Limited-time Deals——**這組需要倒數計時元件(countdown timer)**,目前元件庫沒有這個,請這批一併設計(顯示剩餘時/分/秒,樣式跟其他 badge/標籤視覺語言一致),完成後補進元件庫。

每組用商品卡格線或橫向捲動陳列,商品卡沿用元件庫已定案的樣式(含缺貨/促銷/新品標籤變化)。卡片上的「快速加入購物車」按鈕點擊後,局部更新 header 購物車 badge 數量(**htmx 標註**)。

## 信任區塊 Trust Badges

3–4 組 icon + 文字,例如:全站保固、滿額免運、7 天鑑賞期、信用卡安全支付(可呼應 Stripe 安全性,強化信任感)。

## Footer(全站共用)

多欄式:客服(聯絡我們/FAQ/退換貨政策)、關於(關於我們/隱私權政策/服務條款)、社群連結、電子報訂閱表單(表單送出後局部顯示成功訊息,不整頁刷新——**htmx 標註**)、語言切換、版權宣告。

## 交付要求

- 桌機 1440px + 手機 375px 各一份,完整可互動的 HTML(Tailwind utility class)
- 真實感繁中 3C 商品文案(具體型號、規格、NT$ 價格)
- 這批定案的 Header/Footer 之後每一批畫面直接沿用,不要重新設計
- 用既有的 htmx 藍虛線 / Stripe 灰虛線圖例,標註本批新增的互動區塊:即時搜尋建議下拉、電子報表單送出、加入購物車數量更新
- 新增的「倒數計時元件」設計完後請補進元件庫,後續後台促銷管理等畫面可能會再用到
