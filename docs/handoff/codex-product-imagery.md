## 你要做什麼

替一間叫 **goen(緣)** 的台灣 3C 選品電商產出 16 張商品照 + 1 張首頁主視覺。
商品是虛構品牌,所以不會撞到真實產品的版權。

## 這間店的調性(決定畫面長相)

goen 賣的是「規格看得懂、保固靠得住」的 3C 選品,不是大賣場。網站的設計語言:

- 底色是**暖白**(oklch 0.966 0.005 106,略帶暖調的米白,不是純白 #fff)
- 文字是**暖黑**(oklch 0.22 0.012 107)
- 面板比底色再亮一點點(oklch 0.988),邊框是很淡的暖灰(oklch 0.88)
- 沒有濃烈的品牌色塊,沒有漸層,沒有 3D 光暈,沒有科技感藍光
- 整體是**安靜、有呼吸感、日系選物店**的感覺,接近無印良品或蔦屋家電,
  而不是京東或 Best Buy

**明確不要的**:電商促銷風(爆炸角標、紅黃對比、閃電圖示)、
賽博龐克霓虹、雜亂的道具堆疊、假的「lifestyle 情境」擺拍(手拿咖啡、
筆電上有便條紙那種)。

## 統一的攝影規格(全部 16 張都要一致)

| 項目 | 規格 |
|---|---|
| 尺寸 | 1600 × 1200(4:3 橫式) |
| 格式 | PNG 或 JPEG(伺服器會重新編碼,所以不用壓縮) |
| 背景 | 單一暖白背景,無縫,略有柔和的落地陰影 |
| 光線 | 大面積柔光,單一主光源自左上,無硬邊陰影,無反光板亮點 |
| 角度 | 3/4 側前方視角(產品左前方約 30 度),微俯視約 15 度 |
| 構圖 | 產品置中,四周留白約佔畫面 15%,產品不出血 |
| 景深 | 全清晰,不要淺景深虛化 |
| 道具 | 無。畫面上只有產品本身 |

**一致性是重點** —— 這 16 張會並排出現在同一個列表頁上,光線角度或背景色
不一致會非常明顯。請用同一組參數跑完全部。

## 怎麼交付

檔案給我就好。上傳的部分我這邊有後台可以做(`/admin/products/{slug}/images`,
會自動重新編碼並產生 400/800 兩個縮圖),但**每張圖需要你附一句
繁體中文的替代文字**(alt text),因為那是必填欄位,而且讀螢幕的人靠它
知道圖裡是什麼。

格式像這樣:

```
aurora-edge-7.png — 深綠色霧面手機,正面朝左前方立起,螢幕關閉,背面可見三顆直排鏡頭
```

alt 描述的是**圖裡有什麼**,不是行銷文案。不要寫「時尚優雅的旗艦手機」,
要寫「深綠色霧面手機,三顆直排鏡頭」。
